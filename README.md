## Contenu du dépôt

| Fichier | Rôle |
|---|---|
| [index.html](index.html) | Maquette cliquable du futur site (pages publiques + espace administrateur de démonstration) |
| [PLAN-REFONTE.md](PLAN-REFONTE.md) | Audit du site actuel : erreurs, liens cassés, pages légales manquantes |

## À savoir sur la maquette

- Tout tient dans `index.html`, sans installation : il suffit de l'ouvrir dans un navigateur.
- L'espace administrateur (lien en bas de page) accepte n'importe quels identifiants.
- Les ajouts, modifications et messages restent dans le navigateur et disparaissent au rechargement : rien n'est enregistré ni envoyé.
